# SOC Alert Lab

## Overview

This repository contains simulated Security Operations Center (SOC) investigations. It focuses on analyzing alerts, identifying suspicious activity, and documenting incident response steps in a structured format.

## Purpose

To practice real-world SOC analyst workflows including:

* Alert triage
* Phishing email investigation
* Log analysis
* Incident documentation
* Basic threat intelligence reasoning

## Lab Scenarios

### 1. Phishing Email Investigation

* Identify sender behavior
* Analyze suspicious links and attachments
* Determine if email is malicious

### 2. Suspicious Login Activity

* Review unusual login attempts
* Check IP patterns and geolocation anomalies
* Flag potential account compromise

### 3. Malware Alert Analysis

* Investigate flagged executables
* Understand detection reasoning
* Document response actions

## SOC Workflow Practice

1. Alert Detection
2. Initial Triage
3. Investigation
4. Evidence Collection
5. Decision (True/False Positive)
6. Reporting

## Skills Developed

* Threat detection mindset
* Log interpretation basics
* Incident response documentation
* Cybersecurity analytical thinking
