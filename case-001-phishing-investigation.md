# Case 001: Phishing Email Investigation

## Alert Summary

A user reported receiving a suspicious email requesting urgent password verification and account confirmation.

## Initial Observations

* Sender email appears unusual and does not match official domain structure
* Message contains urgency-based language
* Includes a clickable link claiming to "secure account"
* Grammar inconsistencies detected

## Investigation Steps

### 1. Sender Analysis

* Checked sender domain reputation
* Domain appears newly registered and not associated with known organization

### 2. Link Inspection

* Hover analysis suggests redirect to non-official login page
* URL structure mimics legitimate service but contains slight variations

### 3. Email Content Review

* Uses urgency and fear tactics ("account will be locked")
* Requests sensitive login credentials

### 4. Threat Indicators

* Suspicious domain
* Credential harvesting behavior
* Social engineering patterns

## Conclusion

This email is classified as a **phishing attempt** designed to steal user credentials.

## Response Actions

* Email flagged as malicious
* User advised not to interact with links
* Domain recommended for blocking in mail filters

## Lessons Learned

* Always verify sender domains carefully
* Avoid clicking urgent authentication requests via email
* Use official portals directly instead of email links
